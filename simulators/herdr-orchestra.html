What the server is, in 3 lines

  1. herdr is like a building manager: the server is the office that stays open in the background, and each pane is a room where one AI agent works.
  2. Agents can only see and message each other through that office. If the server isn't running, nobody can find anybody.
  3. Every session: open Terminal, type herdr, start your agents inside it.

Set up your ecosystem

4 steps, tap one for details
1

Start herdr in a project folder

Open Terminal, go into your folder, type herdr.

cd my-project && herdr
2

Open a pane per agent

Split the window, start one agent in each pane.

claude opencode agy
3

Add the herdr skill to Claude

A little instruction sheet so Claude knows the herdr commands.

herdr --skill
